# WordCircle

Ein zweisprachiges SvelteKit-Wortspiel mit DaisyUI und Unplugin Icons. Ziehe Buchstaben in der richtigen Reihenfolge, um Wörter zu bilden und ein sich kreuzendes Raster zu füllen.

## Lokale Entwicklung

```bash
bun install
bun run dev
```

Die Spieloberfläche befindet sich vollständig in `src/routes/+page.svelte`. Rätsel liegen getrennt als `src/lib/data/words.de.json` und `src/lib/data/words.en.json` vor.
